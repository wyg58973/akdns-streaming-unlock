## 它到底怎么解锁

路由发生在 DNS 层。服务器解析 `netflix.com` 时，AKDNS 返回一个同区域的解锁节点，这条请求从能解锁的线路出去。整个过程没有任何代理软件参与，浏览器和播放器侧无感。

没在控制台勾选的域名照常解析、直连。官方公告的说法是，其余流量"基本没有额外延迟，也没有任何东西被代理"。

## 一条命令装完

在 Linux 上用 root 或 sudo 执行：

执行后会进入一个交互菜单。官方给的流程是六步：

1. 在 AKDNS 控制台添加这台机器的 IP

3. 跑 DNS 测速，选出最优节点
4. 设为系统 DNS
5. 在控制台勾选这个 IP 要解锁的服务
6. 复测，确认生效

第 3、4 步在菜单里有一个合并的"测速并设置"选项，少点一次。

## 装之前必须知道的三件事

**第一，"设为系统 DNS"会锁住配置文件。**

这个选项会停用系统上正在管理 DNS 的那一层（systemd-resolved、NetworkManager、resolvconf、netplan 之一），写一份静态 `/etc/resolv.conf` 指向测速选出的节点，再用 `chattr +i` 把文件锁成不可修改，防止 dhclient 或 cloud-init 在重启时覆盖掉。

这一步改的是系统级配置。如果这台机器上还有别的东西依赖原来的 DNS 管理器，比如某些面板、容器网络或者监控脚本，先确认它们不会因为 DNS 管理器被停用而出问题。

**第二，有备份，也能完整还原。**

脚本动任何东西之前会先备份。菜单里的"Restore DNS config"会解锁文件、重新启用原来的管理器，把机器放回原样。官方也写明，脚本只做连通性检测和 DNS 配置，不装代理，不改动其他流量。

**第三，beta 就是 beta。**

解锁失败、想加一个名单里没有的服务，官方给的渠道是 Telegram 群，公告里说反馈走那里最快。这里没有可用性承诺，也没有赔付条款。把系统 DNS 交给一个测试期服务，和在备用机上试水，是两件事。

## 什么人不该用

**需要稳定 SLA 的。** 系统 DNS 是所有网络请求的第一跳，把它指向一个 beta 服务，等于在这条链路上加了一个没有可用性承诺的环节。生产环境、对外提供服务的机器，不适合这么改。

**要解锁的服务不在名单里的。** 60+ 看着多，具体到某部剧、某个地区的某个平台，还是可能没有。beta 期只能提需求等排期。

**不愿意改系统 DNS 的。** 脚本的做法是接管而不是并存。如果你的环境里 DNS 由配置管理工具统一维护，装完还原来还原去，维护成本比省下的时间更高。

想完全自己控制，可以走自建路线：用 dnsmasq 把流媒体域名解析到自己的 VPS，再用 sniproxy 监听 80/443 做反代。前提是手上有一台本身就能解锁的 VPS，这是整个方案的基础。代价在配置量：几十条 `address=/域名/IP` 规则，加上一张 sniproxy 的域名匹配表，Netflix 一套、Disney+ 一套，平台换 CDN 域名就得跟着补。网上流传的教程多是 2020 到 2022 年的，涉及的系统版本（CentOS 7、Ubuntu 16–22）和域名清单都要自己重新核一遍。好处是完全自控、不依赖第三方，坏处是这份维护工作会一直跟着你。

AKDNS 走的是另一个方向：零规则维护，代价是依赖第三方，且在 beta 期。

## 常见问题

**会不会拖慢其他流量？**

没配置的域名照常解析、直连，官方说基本没有额外延迟。要注意的是"设为系统 DNS"之后，所有查询都会先到 AKDNS 节点，包括那些没有解锁需求的域名，解析路径比本地缓存长一点。这一步的影响面比解锁本身大。

**免费到什么时候？**

官方没给期限。2026 年 10 月的公告原文是 open beta、free right now。要长期依赖，按"随时可能变"来规划，别把关键业务压在上面。

**10 个 IP 怎么算？**

官方口径是"添加 10 个 IP"，规则按 IP 生效，每台机器独立配置。换个公网 IP 就要重新添加、重新勾服务。

**网上那些 154.83.83.x 的 DNS 地址还能用吗？**

那是 2025 年的公开列表，一组是各地区解锁地址（HK `.184` 到 DE `.190`），一组是 Akile 及合作机器免白名单的免费组（`.83` 到 `.90`）。2026 年 10 月的 beta 公告没有再列任何固定 IP，改成了脚本测速自动选节点。照着旧列表手填能不能用没有保证，也没必要，走控制台加 IP 加脚本更稳。

**装完怎么确认生效？**

流程最后一步就是复测。勾选服务后再跑一次，没通过就回控制台核对两件事：IP 加对了没，服务勾对了没。
